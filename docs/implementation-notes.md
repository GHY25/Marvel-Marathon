# 구현 결정

- 기준: 제공된 MVP 명세. 템플릿 `master`, `78c3a08ac1799a0721b5451a87419925b540dada`에서 시작.
- 기존 창 위치·크기 복원, 로깅, 환경별 실행을 보존하며 앱 기능을 확장.
- React + HashRouter + 일반 CSS. 사용자 데이터는 Electron Main의 SQLite만 사용.
- SQLite 드라이버는 Electron에 내장된 `node:sqlite`의 `DatabaseSync` 사용. 별도 `better-sqlite3` ABI 재빌드 없이 같은 SQL 트랜잭션과 파일 DB를 제공한다. 템플릿의 Electron 39에서 발견된 의존성 보안 경고를 수정하기 위해 Electron 45.2.3으로 갱신했다. 실제 바이너리의 Node 24.22.2에서 SQLite 열기/쿼리/닫기를 확인했다.
- 공식 근거: [Electron 39 / Node 22.20](https://www.electronjs.org/blog/electron-39-0), [Node SQLite API](https://nodejs.org/download/release/latest-jod/docs/api/sqlite.html).
- 공유 순수 함수가 최신 유효 평점·재관람·랭킹·통계·필터를 계산한다.
- 백업은 JSON 전체 검증 → 사용자 확인 → 복구용 사본 → 트랜잭션 교체 순서.
- Electron의 sandbox/contextIsolation 유지. preload는 `type: module` 프로젝트에서도 실행되도록 `.cjs` 출력.
- 단위/통합 테스트는 임시 DB, Electron UI 테스트는 별도 userData 디렉터리만 사용한다.
- 초기 MVP에는 창작 커버와 앱 아이콘만 포함했다. 후속 요청으로 아래의 선택적 TMDB 포스터·사용자 이미지 기능을 추가했으며, 핵심 감상 기록 기능에는 여전히 계정·API 키가 필요 없다.
- 호환 가능한 보안 패치와 `minimatch` 11.0.4 override를 반영했다. 사용하지 않는 `vite-plugin-electron*` 의존성을 제거했고, 빌드 도구는 개발 의존성으로 이동했다. `npm audit` 0건을 확인했다.
- 명세의 평균 소수점 첫째 자리 반올림은 공통 표시 함수로 처리한다. 원본 평균을 보존하면서 부동소수점 경계값 4.35/4.05가 4.4/4.1로 표시되도록 했다.
- 최소 창 크기는 760×600이며, 좁은 창에서도 랭킹의 감상 횟수와 최근 평가 날짜를 숨기지 않고 재배치한다.
- 복원 성공과 이후 화면 재조회 실패를 구분하고 재시도를 제공한다. 시작 시 저장 폴더를 준비하지 못하면 다른 DB로 우회하지 않고 오류 안내 후 종료한다.

## 우주 수집 UI 및 밝은 테마 확장

- 후속 사용자 요청에 따라 대시보드를 38개의 별과 6개의 Phase 별자리로 구성했다. 배경의 작은 장식별과 달리 선택 가능한 별 38개는 실제 영화와 일대일 대응한다.
- 별과 Phase 완료 상태는 기존 감상 기록에서 계산한다. 별도 업적 DB를 만들지 않아 재관람·삭제·복원과 시청 진행률 사이에 상태 불일치가 생기지 않는다.
- Phase 수집 카드를 선택하면 해당 별자리로 이동하고, 영화 별을 선택하면 기존 상세·감상 기록 흐름으로 연결된다. Phase 이동은 지도에서 다른 영화를 제거하는 필터가 아니다.
- 지도와 수집 토큰은 SVG/CSS로 그려 외부 이미지·API·새 의존성 없이 오프라인으로 동작한다. 여섯 색상은 시각적 수집 장치이며 영화 세계관의 공식 Phase·스톤 대응을 의미하지 않는다.
- 기본 어두운 우주와 밝은 천체 지도 테마를 제공한다. 전역 색상 토큰으로 목록·랭킹·일기·설정·모달까지 적용하며, 테마만 로컬 설정에 저장한다. 감상 DB·IPC·백업 포맷은 변경하지 않았다.

## 탐색 가능한 우주 캔버스

- 정적인 Phase 격자를 하나의 2,400×1,600 논리 좌표 공간으로 확장했다. 비대칭으로 놓인 여섯 별자리와 그 사이의 공간을 드래그로 탐색하며, 38개의 영화 별은 항상 같은 지도에 유지한다.
- 마우스 위치를 기준으로 하는 휠 확대, 짧은 드래그 관성, 확대·축소 버튼, 전체 보기, Phase로 이동을 제공한다. 카메라 이동과 배율에 한계를 두고 드래그와 클릭을 구분해 지도를 옮긴 직후 영화가 열리는 것을 방지한다. 미니맵은 현재 표시 영역을 보여주는 위치 안내다.
- SVG 연결선과 DOM 링크를 함께 사용해 기존 영화 상세 링크의 의미와 키보드 접근을 유지한다. 지도에 초점을 둔 상태에서 방향키·`+`·`−`·`Home`을 사용할 수 있고, 화면 밖의 영화 별에 키보드 초점이 가면 그 별이 보이도록 이동한다.
- 실제 별자리의 서로 다른 실루엣을 참고했다. Phase 1~6은 카시오페이아·백조·오리온·북두칠성·사자자리의 낫·작은개자리를 사용하며, 각 Phase의 영화 수에 맞춰 점과 연결선을 재구성했다. 천체 실측 좌표를 재현하지 않으며, [참고 자료와 조정 이유](constellation-references.md)를 별도로 기록했다.
- 별의 크기와 모양, 은은한 성운과 반짝임으로 공간감을 더했다. 밝은 테마에도 동일한 탐색 기능을 적용하고, 운영체제의 `prefers-reduced-motion` 설정에서는 반복 애니메이션·관성·카메라 전환 애니메이션을 끈다. 외부 이미지·서비스·새 패키지와 DB 변경 없이 구현했다.

## 배경 경계 제거 및 우주 전체 화면

- 2026-11-09 요청에 따라 성운과 장식별을 카메라가 축소하는 사각형에서 분리하여 지도 표시 영역 전체에 그린다. 영화 별과 연결선만 카메라로 이동하므로 축소 시 배경 끝의 네모난 경계가 나타나지 않는다.
- 지도 도구막대에 전체 화면 아이콘을 추가했다. 지도 요소에 [Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)를 적용하여 우주·조작 도구·범례만 표시한다. 종료 버튼과 Esc로 돌아오며, 영화 상세 이동으로 지도가 사라질 때도 전체 화면을 해제한다. 전환 실패는 지도 안에서 안내한다.
- [Electron 권한 검사](https://www.electronjs.org/docs/latest/api/session)는 앱 창의 메인 프레임과 정확한 문서 URL에 한해 `fullscreen`만 허용한다. 사용자 동작 없는 `automatic-fullscreen`과 다른 권한은 거부한다. 기존 sandbox/contextIsolation 및 typed IPC는 유지했다.
- 전체 화면에서 앱을 종료해도 다음 실행에 일반 창 크기를 복원하도록 `getNormalBounds()`를 저장한다. 감상 기록·백업 형식은 변경하지 않았다.

## 별 클릭 입력 및 본문 가독성

- 숫자 선택 메뉴를 제거하고 별 다섯 개를 직접 누르는 버튼으로 바꿨다. 다른 별을 처음 누르면 그 별까지의 반 점(세 번째 별은 2.5점)을 선택하고, 같은 별은 반 개와 한 개 사이를 전환한다. 평점 지우기와 선택 점수의 읽기 전용 표시를 유지하며 Enter·Space도 같은 동작을 수행한다.
- 영화 상세의 감상 기록을 날짜 → 평점 → 감상평의 세로 순서로 배치했다. 날짜 20px, 평점 22px, 감상평 17px로 읽기 쉽게 강조하고 수정·삭제 버튼도 키웠다.
- 왼쪽 패널의 글씨 크기는 유지했다. 메인 화면의 본문·버튼·설명·검색·필터·통계·우주 지도와 모달의 작은 글씨를 키웠으며, 입력 필드는 16px로 맞췄다. 작은 창에서는 글씨를 과도하게 줄이는 대신 줄바꿈과 모달 스크롤을 사용한다.

## 선택적 TMDB 포스터와 사용자 이미지 (2026-11-09)

- 원래 명세에서 미뤄 둔 외부 포스터와 사용자 커버를 후속 사용자 요청으로 구현했다. 감상 기록·통계·우주 지도는 계속 API 키와 인터넷 없이 동작하며, 설정에서 명시적으로 가져오기를 실행할 때만 Main 프로세스가 TMDB에 연결한다.
- 공식 [검색 API](https://developer.themoviedb.org/reference/search-movie)로 영문 제목과 개봉 연도를 대조한다. 정규화한 제목과 연도가 유일하게 일치할 때만 연결한다. 후속 영어 원문 요청에 따라 [이미지 API](https://developer.themoviedb.org/reference/movie-images)로 영어 → 언어 없음 순서의 세로 포스터를 선택한다. 한국어 등 다른 언어와 언어를 확정할 수 없는 검색 결과의 기본 포스터는 사용하지 않는다. 지원하는 포스터가 없으면 기존 커버를 유지하고 이유를 안내한다.
- [공식 인증 방식](https://developer.themoviedb.org/docs/authentication-application)에 따라 API Key(v3)와 Read Access Token(Bearer)을 모두 지원한다. Electron safeStorage로 암호화한 값만 DB에 저장하고 조회 IPC는 저장 여부만 반환한다. 평문 저장밖에 지원하지 않는 환경에서는 키 저장을 거절하며 기존 감상 기능과 직접 이미지는 계속 사용할 수 있다.
- 네트워크 대상은 고정된 TMDB API와 이미지 CDN뿐이다. 리다이렉트를 차단하고 다운로드 시간·용량, 이미지 이름과 형식·픽셀 수를 제한한다. API 키를 이미지 CDN에 보내지 않으며 오류에 URL·키·원본 예외를 포함하지 않는다. 별도 외부 이미지 CSP 허용이나 범용 파일 접근 IPC를 추가하지 않았다.
- SQLite 스키마를 1 → 2로 올려 포스터 JPEG와 암호화 설정 테이블을 추가한다. 기존 영화·감상 기록은 보존한다. 자동·사용자 이미지를 별도로 보관하고 사용자 이미지가 있으면 우선 표시한다. 직접 고른 원본은 최대 500×750 JPEG로 복사해 원본 파일 이동에도 영향을 받지 않는다.
- 공통 MovieCover가 검증된 로컬 JPEG data URL을 표시하므로 목록·상세·대시보드·랭킹·일기에 일괄 적용된다. 추가 네이티브 패키지나 원격 렌더러 이미지 접근 없이 기존 CSP를 유지했다. 데이터가 현재 38편보다 크게 늘어나면 썸네일 전용 로컬 프로토콜과 별도 캐시 API를 검토할 수 있다.
- 가져오기 진행률과 실패 이유, 중지·재시도·자동 캐시 갱신, 키 삭제를 제공한다. 중지·실패가 이미 저장된 포스터를 제거하지 않으며, 새로 받기에서도 사용자 이미지는 덮어쓰지 않는다. 영화 상세에서 원래 자동 포스터(없으면 우주 커버)로 되돌릴 수 있다.
- 감상 기록 JSON 백업 형식은 유지한다. 포스터·키는 내보내지 않고 복원 시에도 건드리지 않는다. 이를 설정과 README에 안내한다. 사용자 이미지 전체 백업/기기 간 이전은 후속 범위다.
- 설정 앱 정보에 TMDB 공식 로고와 필수 출처 고지를 추가했다. 영화 포스터는 배포본에 사전 포함하지 않는다. 실제 키를 제공받지 않았으므로 TMDB 실서버 인증·38편 실데이터 매칭은 미검증이며, 테스트는 TMDB 형식의 고정 응답을 주입하되 실제 IPC·이미지 처리·SQLite·Windows 암호화·재시작을 사용한다.

## 영어 원문 포스터로 변경 (2026-11-09)

- 포스터 아래의 앱 제목은 이미 영어였으며, 한국어 제목은 한국어판 포스터 이미지에 포함된 글씨였다. 사용자가 영어 원문을 요청하여 처음 구현한 한국어 우선 선택을 영어 우선으로 바꿨다.
- TMDB 이미지 요청은 `language=en`, `include_image_language=en,null`로 제한한다. 응답에서도 영어를 먼저 선택하고, 없으면 언어 표시 없는 포스터만 사용한다. 다른 언어의 이미지나 언어 정보가 없는 검색 결과의 기본 포스터로 되돌아가지 않는다. 적합한 이미지가 없을 때는 기존 이미지를 지우지 않고 실패 이유를 표시한다.
- 설정의 갱신 옵션을 **저장된 포스터도 영어로 새로 받기**로 명시했다. 이전 한국어 이미지는 이 옵션을 켜고 다시 가져오면 교체된다. 업데이트만으로 기존 캐시를 지우거나 네트워크 요청을 시작하지 않으며, 사용자가 직접 고른 이미지는 유지한다.
- DB·IPC·감상 기록 형식은 그대로 유지한다. 테스트는 높은 평점의 한국어 포스터보다 영어 포스터가 선택되는지, 지원 언어가 없을 때 검색 기본 이미지로 우회하지 않는지, 이전 버전 자동 캐시를 실제 Electron의 새로 받기로 교체하는지 검사한다.

## 디즈니+ MCU 시즌과 스페셜 확장 (2026-11-09)

- 사용자 요청에 따라 영화 전용 상태를 `f5af38a`로 먼저 커밋하고, 디즈니+ MCU 작품만 추가했다. 기존 38편 + 18개 시리즈의 23개 시즌 + 스페셜 3편, 총 64개 기록 단위다. [포함 목록·공식 출처·제외 기준](catalog-scope.md)을 별도로 정리했다. 원래 명세의 TV 제외 조건은 이 후속 요청으로 변경되었다.
- 시즌마다 고정 ID를 부여하고 기존 감상 CRUD·재관람 모델을 재사용한다. 서로 다른 영화·시즌·스페셜 수로 진행률을 계산하고, 각 항목의 최근 유효 별점으로 평균과 순위를 계산한다. 에피소드별 진행률은 구현하지 않았다. VisionQuest 시즌 1에는 공개 중 안내를 표시한다.
- 작품 목록·대시보드·감상 일기·랭킹·통계에 유형 필터를 추가했다. 통계의 감상 횟수·최근 기록도 선택한 유형에 한정한다. 기존 영화 개봉 순서는 유지하고 그 뒤에 디즈니+ 작품을 시즌 공개순으로 표시한다.
- DB schema 3은 기존 movies 테이블에 유형·시리즈명·시리즈 최초 연도·시즌·공개 상태 열을 추가한다. 영화 ID, 감상 기록, 자동·사용자 포스터, 암호화 키를 유지하며 마이그레이션과 카탈로그 동기화를 하나의 트랜잭션으로 수행한다. 기존 movies/movieId IPC 이름과 JSON formatVersion 1은 호환성을 위해 유지했다. 구버전 백업 복원과 재실행을 테스트했다.
- 지도는 2,400×2,000으로 확장했다. 기존 영화의 별자리 좌표는 유지하고 Phase 4~6 아래에 시즌·스페셜 별길을 추가했다. 필터로 숨기거나 다시 표시해도 별의 좌표가 달라지지 않는다. 해당 유형의 작품이 없는 Phase 이동 버튼은 비활성화한다.
- TMDB TV 검색은 시즌 연도가 아닌 시리즈 최초 공개 연도로 매칭한다. 시즌별 영어·언어 없음 이미지를 우선하며, 정상 응답에 적합한 시즌 이미지가 없는 경우에만 같은 언어 기준의 시리즈 이미지로 대체한다. API 오류·잘못된 응답은 대체 이미지로 숨기지 않는다. What If...?는 실제 검색에서 동명·동년 결과가 중복되어 검증한 시리즈 ID 91363을 추가 대조한다.
- 실제 계정으로 추가 26개 항목의 포스터 다운로드·이미지 변환을 확인했다. 사용자 DB는 읽기 전용으로 열었고 다운로드는 격리된 진단 폴더에만 저장했다. 키 평문이나 실제 포스터를 소스·배포본에 포함하지 않는다. 앱 설정에서 가져오기를 실행해야 사용자 컬렉션에 새 포스터가 저장된다.
- 이전 영어 포스터 진단에서 발견한 개발 Main 프로세스 갱신 문제를 해결하도록 `npm run dev`에 `--watch`를 추가했다. 포스터 다운로드 중에도 저장·실패 수를 표시한다. 기존 앱이 실행 중이라면 한 번 종료 후 새 명령으로 실행해야 한다.
- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`와 기존 좁은 typed IPC를 유지한다. 새 의존성이나 렌더러 네트워크 권한은 추가하지 않았다.

주요 변경 파일: `src/shared/{catalog,types,media,statistics,validation}.ts`, `electron/db/repository.ts`, `electron/services/tmdb-client.ts`, `src/renderer/components/{MediaFilter,UniverseMap,EntryForm,PosterControls,StatisticsCards}.tsx`, `components/universe/constellations.ts`, `pages/{Dashboard,Movies,Journal}.tsx`, `App.tsx`, `src/styles/Media.css`, `package.json`. 새 시나리오는 `tests/series.test.ts`, `tests/e2e/series.spec.ts`에 있고 기존 테스트의 영화 전용 수치와 화면 문구도 갱신했다.
