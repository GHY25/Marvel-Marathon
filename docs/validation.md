## 자동 검증 범위

- 카탈로그 38편, 유일 ID/개봉 순서 1~38, 페이즈별 6/6/11/7/6/2.
- 새 DB, 반복 seed, 앱 재실행 이후 기록 보존, 미래 스키마 파괴적 초기화 금지.
- 같은 영화의 재관람, 날짜·작성 시각·ID 기준 정렬, 최신 미평가 기록과 이전 유효 평점 유지.
- 영화별 평균, 동점 랭킹, 재관람 수, 별점 분포, 페이즈 집계, 전체 미시청/전체 시청.
- 윤년/실제 달력/미래 날짜, 별점 범위·타입, 리뷰 길이·Unicode, 존재하지 않는 ID 검증.
- 한 기록만 수정·삭제, 작성 시각 유지, 마지막 기록 삭제 시 미시청 전환.
- JSON 왕복, 중복 ID, 미지원 포맷, 손상 JSON/UTF-8, 크기 초과 거부.
- 복원 확인 취소 시 무변경, 복구 사본 생성 실패 시 무변경, DELETE 후 SQL 실패의 rollback.
- IPC 발신 창·메인 프레임·정확한 URL 검증, http(s) 외 외부 링크 차단.

## 실제 Electron 통합 시나리오

`tests/e2e/app.spec.ts`는 렌더러 mock 데이터를 사용하지 않습니다. 실제 preload → IPC → SQLite를 거칩니다.

1. 빈 대시보드 → 사이드바 → 38편 목록 → 페이즈/제목/시청 상태 교집합 → 필터 초기화.
2. 영화 카드 클릭 → Iron Man 4.0/4.5 두 기록 입력 → +0.5 표시 → 종료/재실행 후 동일 기록.
3. Thor 3.5 입력 → Iron Man 미평가 재관람 → 영화별 평균 4.0 유지, 랭킹/일기 확인.
4. 삭제 취소/확인, 감상평 수정, ID·날짜·평점·리뷰·시각이 보존되는 백업 복원.
5. 손상 백업 거부 후 기존 데이터 보존, 잘못된 IPC 입력 거부.
6. 전체 페이지를 1000×800 및 최소 창 크기 760×600에서 확인. 본문 내부 가로 넘침, 랭킹 감상 횟수·평가 날짜 표시, 렌더러 예외 0건 확인.
7. sandbox/contextIsolation=true, nodeIntegration=false 실제 창 설정 확인.
8. 복원 직후 조회 한 번만 실패하도록 주입 → 정확한 오류 표시 → 실제 DB 복원 확인 → 다시 시도로 화면 복구.
9. 서로 다른 Phase 3 영화 10편에 총 87개의 반별점 단위를 저장하여 전체·Phase 평균 4.35가 4.4로 표시되는지 확인.

자동 백업 시나리오에서는 파일 선택창 응답과 확인 응답만 테스트 코드에서 대체했습니다. JSON 파일 I/O, 복구 사본 및 SQLite 복원은 실제 코드입니다.

추가 장애 시나리오는 테스트 중 Electron IPC 내부 핸들러를 한 번만 감싸 조회 오류를 반환하고 즉시 원래 핸들러로 복구합니다. 이 시나리오의 데이터 복원은 실제 서비스를 사용하며 제품 코드에 오류 주입 기능을 넣지 않았습니다.

별도의 임시 DB에서 Windows 기본 저장 대화상자로 파일 이름을 입력하고 저장하여 JSON 백업 생성과 앱 성공 알림을 직접 확인했습니다. 기본 열기 대화상자도 표시되는 것을 확인했지만, 사용자가 테스트 창을 조작하기 시작하여 수동 복원 완료까지는 검증하지 않았습니다. UI 자동화의 대화상자 요소 캐시 오류는 좌표·키보드 입력으로 저장 단계까지 우회했습니다.

```powershell
# 빌드 앱
npm run test:e2e

# 개발 renderer + 실제 Electron
$env:MARATHON_TEST_DEV='1'
npx playwright test
Remove-Item Env:MARATHON_TEST_DEV

# 배포 실행파일
$env:MARATHON_EXECUTABLE='C:\HY\marvel-marathon\release\win-unpacked\Marvel Marathon.exe'
npx playwright test
Remove-Item Env:MARATHON_EXECUTABLE
```

## 후속 요청: 우주 수집 UI와 밝은 테마

2026-11-05에 사용자가 요청한 우주 기반 UI와 라이트 모드를 추가했습니다. 기존 감상 기록과 SQLite·IPC·백업 형식은 그대로 사용합니다.

- 38개 실제 영화 별, 6개 Phase 별자리, 완료한 Phase의 빛 수집 토큰.
- 미평가 감상도 별 점등, 재관람은 중복 집계하지 않음. 마지막 기록 삭제 및 백업 복원 시 별과 수집 상태 재계산.
- Phase별 확대, 마우스·키보드 별 선택, 영화 상세·감상 기록 흐름 연결.
- 네이비 밤하늘과 아이보리 천체 지도 테마. 상단 토글·설정 선택 UI, 재실행 후 테마 유지.
- 밝은 지도 보조 글자 대비 보완, 테마 전환 중 글자·배경색이 어긋나는 짧은 전환 제거.

변경 파일: `UniverseMap.tsx`, `Universe.css`, `ThemeControls.tsx`, `useTheme.ts`, `Theme.css`, `CosmicJourney.css` 추가. `App.tsx`, `Dashboard.tsx`, `Journal.tsx`, `Movies.tsx`, `Common.tsx`, `useMarathonData.ts`, `index.css`에 탐색·테마·수집 안내를 연결했습니다.

## 후속 요청: 드래그하는 우주와 실제 별자리 배치

같은 날 정적인 6개 영역을 하나의 2,400×1,600 우주 캔버스로 변경했습니다. 마우스 드래그·관성, 커서 기준 휠 확대, 확대·축소와 전체 보기, Phase 이동 애니메이션, 현재 영역 미니맵을 제공합니다. 영화 별 38개는 항상 지도에 남으며, 감상 기록 집계와 상세 연결을 유지합니다.
